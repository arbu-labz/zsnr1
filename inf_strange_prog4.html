Episode Stranger Things — S01E04 Python: lists + append + for

The List of Clues

One new Python skill per episode. Today: collecting data with a list, using append(), and summing with a for loop.

The news spreads fast in Hawkins. People whisper in grocery store aisles. They stop talking when someone walks too close. Then it becomes official: they found a body in the water.

Mike hears it and feels his chest tighten. Lucas goes quiet. Dustin looks away. None of them want to say the thought out loud: What if it’s Will?

But Eleven shakes her head hard. “No,” she says. One word, sharp like a nail.

Hopper doesn’t trust the story either. The photos look wrong. The timing feels wrong. The whole thing smells like someone trying to close a case too quickly. So he does what he always does when a town lies: he starts collecting details.

“We need a list,” he mutters. “A real list.”

Joyce also makes a list, even if she doesn’t call it that. She circles letters on the wall. She writes down which lights blink. She keeps track, because memory isn’t safe anymore.

In the basement, Mike opens the laptop again. “We already know input,” he says. “We already know decisions and loops.” Dustin nods. “So what’s next?”

Mike points at the notebook full of scribbles. “Next is collecting more than one thing. In Python, we do that with a list.”

He types: 

# A list can store many values in one place
clues = []

Lucas watches. “So it’s like a box where we throw evidence.”

“Exactly,” Mike says. “And when we find a new clue, we add it with append().” 

clues.append("A light blinked twice")
clues.append("The phone made static")
clues.append("Eleven said: No")

Dustin grins. “So now we can keep adding.”

But today they need something simple and practical: numbers. Mike wants the program to ask for three “signal strengths” — like three readings from a radio. If the signals add up to something big, it means “keep searching.” If they are small, maybe it was just noise.

“We’ll take three numbers,” Mike says. “Put them in a list. Then sum them.”

Dustin makes a classic mistake first. He tries to put numbers into a list without converting. The list becomes a list of strings, and the total becomes nonsense. 

# Controlled mistake: inputs are strings (DON'T do this)
signals = []
signals.append(input("Signal #1: "))
signals.append(input("Signal #2: "))
signals.append(input("Signal #3: "))

Lucas squints. “So what’s wrong?”

Mike taps the screen. “We forgot conversion. Always convert when you need real numbers.”

He fixes it. Three inputs. Three numbers. One list. 

signals = []

for i in range(3):
    x = float(input(f"Signal #{i+1}: "))
    signals.append(x)

“Now we have three values,” Dustin says. “But how do we add them?”

Mike points at the next step: a loop that walks through the list. “A for loop,” he says. “Like checking each clue one by one.” 

total = 0
for x in signals:
    total += x

The basement light flickers once, like it approves.

In the Byers house, Joyce stares at the wall of lights. She doesn’t know Python, but she understands patterns: one blink, then another, then another— the same action repeated until it becomes meaning.

In the quarry, Hopper looks at the “body” again. His instincts scream: something doesn’t add up.

In the basement, Mike prints the result: 

print(f"Total signal: {total}")

“So,” Lucas says, “a list is how we keep the evidence together.”

Mike nods. “Yeah. Because one clue is easy to ignore. But a list of clues… that’s harder to erase.”

Student Task

Write a Python program that collects three numbers from the user into a list and then prints their sum.

  1. Create an empty list.
  2. Use a for loop with range(3) to ask for 3 numbers.
  3. Convert each input to a number (float is fine) and add it to the list using append().
  4. Use another for loop to calculate the total sum of the numbers.
  5. Print the result like: Total: 15.
# FINAL CODE (copy)

numbers = []

for i in range(3):
    x = float(input(f"Enter number #{i+1}: "))
    numbers.append(x)

total = 0
for x in numbers:
    total += x

print(f"Total: {total}")

Study notes

Today’s skill: store many values in a list. Add items with append(). Walk through the list with a for loop.

  • List: numbers = []
  • Add item: numbers.append(x)
  • Loop: for i in range(3):
  • Sum: start with total = 0, then total += x
  • Common mistake: forgetting conversion (strings instead of numbers)
