Episode Stranger Things — S01E01 Python basics

The Vanishing Signal

A learning story that secretly teaches a tiny Python program: read two numbers → add → print.

The night in Hawkins feels normal—until it doesn’t. One moment, the road is quiet. The next, Will is gone. His bicycle lies like a dropped sentence, unfinished.

The next day, Mike, Dustin, and Lucas sit in Mike’s basement, surrounded by board games and nervous silence. Mike opens his laptop like it’s a flashlight.

“We can’t fight a monster,” Dustin says, “but we can build a tool. A tiny one.”

Lucas raises an eyebrow. “A tool for what?”

Mike taps the keyboard. “For thinking clearly. Step one: ask the user for information.”

Mike writes a single line and turns the screen toward the others. “In Python,” he says, “the simplest way to get text from the user is input().” It’s like listening for a message in the dark. 

# 1) Read something from the keyboard
first = input("Enter the first number: ")

Dustin leans in. “So… we got a number?”

Mike shakes his head. “Not yet. Here’s the trick: input() gives us a string, like a label, not a real number.”

Lucas frowns. “Why does that matter?”

Mike types fast—then demonstrates the mistake on purpose. 

# This looks like math, but it isn't:
a = input("Enter A: ")
b = input("Enter B: ")
print(a + b)  # "2" + "3" becomes "23"

“If we type 2 and 3,” Mike explains, “Python might glue the text together: "23". That’s not addition. That’s just two strings holding hands.”

A soft wind hits the basement window. The boys freeze. For a second, the glass reflects a figure—too pale, too still—then nothing.

Mike swallows. “Okay. Real numbers. We need a conversion.”

He writes: int() for whole numbers, or float() if we want decimals. “Let’s use float,” Dustin says. “What if the Upside Down charges taxes with decimals?” 

# 2) Convert strings to numbers
a = float(input("Enter the first number: "))
b = float(input("Enter the second number: "))

Lucas points at the variables. “So a and b are containers?”

“Exactly,” Mike says. “Variables store values—like keeping two clues in your pocket.”

Somewhere across town, Joyce sits by the phone, staring at it like it might blink. In the woods, the air feels wrong, as if the world is buffering.

Back in the basement, the boys are ready for the simplest spell in programming: take two numbers, add them, and show the result. 

# 3) Add the numbers
sum_ = a + b

# 4) Print the result (friendly output)
print(f"Sum: {sum_}")

Dustin nods. “So the computer does exactly what we say.”

“Yes,” Mike replies. “And only what we say. That’s why structure matters.”

Lucas suddenly asks, “What if someone types ‘hello’ instead of a number?”

Mike pauses. “Then Python complains with an error. That’s fair. But we can be polite and catch it.”

He adds a safety net—optional, but smart. 

try:
    a = float(input("Enter the first number: "))
    b = float(input("Enter the second number: "))
    print(f"Sum: {a + b}")
except ValueError:
    print("Please type a number (e.g., 12 or 3.5).")

The house creaks. The lights flicker once. The boys stare at the screen— not because the code is scary, but because it’s clear. Two inputs. Two conversions. One addition. One result.

And in a world where something impossible has taken Will, even a small working program feels like a candle in the dark.

Final takeaway: If you can write this program, you’ve learned the core pattern: input → convert → compute → output. That pattern will return again and again—like a theme song. 

# ✅ Minimal version (recommended for a first try)
a = float(input("Enter the first number: "))
b = float(input("Enter the second number: "))
print(f"Sum: {a + b}")

Study notes

Goal: write a Python program that adds two numbers typed by the user. Remember: input() returns text → convert it with int() or float().

  • New IT words (today): variable, input, convert, output, exception
  • Core pattern: input → convert → compute → print
  • Common mistake: no conversion ⇒ "2"+"3" becomes "23"

Student Task

Write a Python program that:

  1. Asks the user to enter two numbers using the keyboard.
  2. Converts the inputs to numbers (int or float).
  3. Adds the two numbers.
  4. Displays the result in a clear message, e.g. Sum: 7.

Requirements:

  • Use input() for both values.
  • Store values in variables (for example: a, b).
  • Use print() to show the final sum.
  • Your program must work for inputs like 2 and 3 (output: 5).
