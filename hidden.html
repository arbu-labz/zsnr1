“A webpage has two sides: what you see, and what the browser reads.”

In IT lessons we learn that a website is built from HTML. HTML can also include comments. Comments are not shown like normal text.

2) Student Guide (read carefully)

Sometimes the important information is not in the main text. It can be in the source of the page. If you want to understand how a page works, you look at its source.

Quick checklist:

  • Visual text is only one part of a page.
  • In HTML, comments can hide notes.
  • Experts read the page source to learn more.
  • When you find a comment, read it carefully.
  • Some comments contain small “staff notes”.
  • On this page, one staff note is very important.
  • Usually it looks like a short code.
  • Remember: comments are inside the HTML.
  • Check the bottom of the source too.
  • Enter the code in the form.
