Episode Stranger Things — S01E02 Python: if / elif / else

The Rule of Maple Street

Learning Story (B1+/B2): one new Python skill per episode. Today: if / elif / else — making decisions.

Hawkins wakes up like nothing happened. The school bell rings, kids laugh, and teachers talk about homework. But Mike’s face is pale. Lucas tries to act normal, and Dustin keeps making jokes that don’t land. Will is still missing, and the silence around his name feels heavy.

After school, they ride their bikes fast, cutting through streets that suddenly feel too wide. When they reach Mike’s house, the basement lights hum softly, like they’re tired of pretending.

“We need a plan,” Lucas says. “Not another guess.”

Mike opens his laptop. “Okay. Today we make rules. Real rules.”

That afternoon, a stranger appears on Maple Street—a girl with a shaved head, a hospital gown, and eyes that watch everything. She looks like she ran away from a nightmare. The boys freeze when they see her, standing near the woods like a warning sign.

Dustin whispers, “She’s… a weirdo.”

“No,” Mike replies, softer. “She’s scared.”

The girl doesn’t say much. She only shakes her head when Mike says “police.” She points toward the woods like it’s a door that shouldn’t be opened.

Later, in the basement, the boys argue about what to do. Lucas wants to call someone. Mike wants to help her. Dustin wants data. And suddenly Mike says something that sounds like coding, not just fear.

“We need decisions,” he says. “In Python, decisions are made with if.”

Lucas crosses his arms. “Like a rule?”

“Exactly,” Mike says. “A rule with a test. If the test is true, you do one thing. Otherwise, you do something else.” 

# A decision gate in Python:
age = 15

if age >= 18:
    print("Adult")
else:
    print("Teen")

Dustin points at the indentation. “Why the spaces?”

“In Python,” Mike answers, “indentation is structure. No braces. The spaces are the walls.”

They decide to build a tiny “rule-checker” program—something that behaves like their situation: if the girl is safe, keep her hidden. else, don’t risk it. But they need a simple signal—something the user can type.

“Let’s make the user choose,” Dustin says. “Type 1 for ‘safe’, 0 for ‘not safe’.”

Mike types quickly: 

choice = int(input("Is it safe? Type 1 for YES, 0 for NO: "))

if choice == 1:
    print("Hide her. Keep her warm.")
else:
    print("Don’t trust it. Be careful.")

The basement feels colder when the program prints the second line. Like the laptop knows the truth and doesn’t want to say it out loud.

But then Lucas notices a problem. “What if the user types 5?”

Dustin shrugs. “Then the program still chooses the else path. That’s… messy.”

Mike nods. “We need a third path. That’s where elif comes in.” 

choice = int(input("Type 1 (YES) or 0 (NO): "))

if choice == 1:
    print("YES: proceed.")
elif choice == 0:
    print("NO: stop.")
else:
    print("Invalid choice. Type 1 or 0.")

“Now the program has manners,” Dustin says. “It tells you when you mess up.”

Across town, Joyce Byers paints letters on the wall. Her hands shake, but she keeps going. In the police station, Hopper listens like he doesn’t want to believe. And somewhere in the woods, the air feels wrong—like an invisible wire is buzzing.

Back in the basement, Eleven finally speaks a word that hits the room like a dropped glass.

“Will,” she says.

Mike’s breath catches. Dustin’s eyes widen. Lucas looks away, because hope can feel like a trap.

Mike turns back to the screen. “Then we do the next rule,” he whispers. “If we can find a sign… we keep searching. Else… we don’t stop anyway.”

In Hawkins, rules don’t stop monsters. But they stop panic. And in Python, if doesn’t change reality— it only helps you choose the next step, clearly.

Student Task

Write a Python program that asks the user for two numbers and then uses if / elif / else to decide what to print:

  1. Read two numbers from the keyboard.
  2. Add them together.
  3. If the sum is greater than 10, print: Big sum.
  4. If the sum is exactly 10, print: Exactly ten.
  5. Otherwise, print: Small sum.
  6. Always print the numeric result as well (e.g. Sum: 12).
# FINAL CODE (copy)

a = float(input("Enter the first number: "))
b = float(input("Enter the second number: "))

s = a + b
print(f"Sum: {s}")

if s > 10:
    print("Big sum")
elif s == 10:
    print("Exactly ten")
else:
    print("Small sum")

Study notes

Today’s Python skill: decisions with if / elif / else. Remember: == compares, and indentation (spaces) defines the block.

  • Core idea: test → choose a path
  • Compare with: >, <, ==
  • Common mistake: forgetting indentation
  • Mini pattern: input → compute → if/elif/else → print

Phrasal verbs (5)

  1. figure out — understand something
  2. set up — arrange / prepare
  3. hold on — wait / keep something
  4. check out — examine
  5. mess up — make a mistake
