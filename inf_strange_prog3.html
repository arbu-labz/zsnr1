Episode Stranger Things — S01E03 Python: while + try/except

The Loop in the Lights

One new Python skill per episode. Today: repeat until it works — while + safe input with try/except.

Hawkins is quiet, but it doesn’t feel peaceful. It feels like the town is holding its breath. In the Byers house, Joyce doesn’t sleep. She sits close to the phone and listens to the static, as if it might turn into a voice.

On the walls, Christmas lights hang in messy lines. They look silly in November, but Joyce doesn’t care. The lights are her map. One blink can mean “yes.” Two blinks can mean “no.” A long flicker can mean “run.”

“Talk to me,” she whispers. “Just… give me a sign.”

In Mike’s basement, the boys watch Eleven with worried eyes. She sits on the couch like a frightened animal, eating slowly. Mike tries to keep his voice calm.

“We need a better system,” he says. “Something that repeats. Something that checks again and again.”

Dustin nods. “Like Joyce’s lights. She keeps asking until she gets a real answer.”

Mike smiles once—small and tired. “Exactly. In Python, that’s a while loop.”

Mike opens a blank file and writes a simple idea: keep asking the user for a number until the input is correct. Not because the computer is smart—because it is patient. 

# A loop repeats while a condition is True
# Think: Joyce keeps asking the lights again and again.

while True:
    print("The question returns...")

Lucas leans closer. “So this never stops?”

“Not unless we break it,” Mike says. “A loop is like a hallway. break is the door.”

Dustin points at the keyboard. “But people type weird things. What if they type 'abc'?”

Mike nods. “Then Python throws an error. Like the lights exploding.”

He writes the safety net: try/except. “Try the risky thing,” he explains. “If it fails, catch it and continue.” 

while True:
    try:
        a = float(input("Enter the first number: "))
        b = float(input("Enter the second number: "))
        break
    except ValueError:
        print("Please type numbers only (example: 3 or 3.5).")

Eleven watches the screen. Her eyes are dark pools, reflecting the code like a secret.

Then Mike makes a mistake on purpose—to show the danger. He forgets the break. 

# Controlled mistake: no break (DON'T do this)
while True:
    a = float(input("Enter A: "))
    b = float(input("Enter B: "))
    print(f"Sum: {a + b}")

Lucas laughs nervously. “So it keeps asking forever.”

“Yes,” Mike says. “Sometimes that’s useful. But today we want it to stop after success. We need the door.”

Outside, the wind hits the windows. Joyce’s lights blink once—then twice—then flicker like a heartbeat. Joyce stands up so fast her chair falls.

“Yes,” she breathes. “Yes, you’re there.”

In the basement, Mike finishes the tiny program. It feels like the same idea: ask, check, repeat… until it’s real. 

# FINAL CODE (copy)

while True:
    try:
        a = float(input("Enter the first number: "))
        b = float(input("Enter the second number: "))
        break
    except ValueError:
        print("Please type a number (example: 12 or 3.5).")

print(f"Sum: {a + b}")

Dustin exhales. “So the loop is our patience.”

Mike nods. “And the try/except is our shield.”

The lights upstairs flicker again, far away. In Hawkins, even answers come through static. But with the right structure, you can keep asking until you get one.

Task

Create a Python program that keeps asking the user for two numbers until the input is correct. Then it prints the sum.

  1. Use a while True loop.
  2. Inside the loop, use try/except to handle wrong input.
  3. If the input is correct, stop the loop using break.
  4. After the loop, print the sum like: Sum: 8.

Study notes

Today’s skill: keep asking until success. while repeats. break exits. try/except prevents the program from crashing.

  • Pattern: loop → try input → if ok: break → print
  • Common mistake: forgetting break (infinite loop)
  • Use case: safe input from the user

Phrasal verbs (5)

  1. keep on — continue doing something
  2. try out — test something
  3. mess up — make a mistake
  4. break out — escape / exit suddenly
  5. hold back — stop yourself
